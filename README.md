# Glorioso Pudim
Página web responsiva realizada com HTML, CSS e JS. E protótipos realizados com Figma, veja clicando [aqui](https://www.figma.com/proto/UsyCjvMaC29Rsue1t6h90d/Glorioso-Pudim?t=O4XX237n96Jza0D7-1)

Consiste em uma landing page que apresenta os produtos aos consumidores, com um cardápio e informações sobre o glorioso pudim, além de possuir o link direto com o whatssap para a venda.
